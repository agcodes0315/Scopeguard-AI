The differentiator · Decision replay

One request. Its full promise history.

A Testimonials page may be outside a five-page agreement today. But if the freelancer later records a reviewed, agreement-specific exception, ScopeGuard can retrieve that history for a matching request. An unrelated checkout request or a changed agreement must not inherit that exception automatically.

Graph evidence path: Project → Active agreement → Relevant clause → Client request → Human-reviewed exception. Previous approval remains subject to verification.
Important: This is a visual walkthrough. Graph evidence shown here is schematic. For live Cypher queries, agreement-version replay and human-reviewed decisions, run the local Atlas Decision Desk from the repository.

How the graph changes guidance

Matching reviewed exception found

Same request under the same agreement version → surface exception conditions, require human verification.

03
Different request or version

Online checkout or an updated agreement → do not reuse the old exception; reassess.
