From request to resolution

ScopeGuard turns “one small change” into a structured, explainable, human-reviewed workflow.

01. Review the agreement

Identify the original deliverables, revision limits, and clauses that define what is already included in scope.

02. Analyze with Gemma

Compare the client request against the agreement and surface evidence-backed flags for included work, extras, or review-needed cases.

03. Request approval

Prepare a clear human-priced proposal so the client understands the additional work, effort, and approval needed before execution.

04. Remember decisions

FalkorDB connects agreements, requests, and past decisions so the next similar request can be checked against real project history.

Why this matters

Freelancers often lose time and money when scope discussions are scattered across chats, calls, and vague verbal approvals.

  • Reduces missed billing opportunities for extra work
  • Creates evidence-backed, client-friendly communication
  • Helps avoid disputes around “included” vs “additional” requests
  • Builds reusable decision memory across project iterations

Want to use the actual AI workflow?

ScopeGuard's complete application currently runs locally with Ollama and FalkorDB. It supports agreement uploads, evidence-backed classification, graph memory, human pricing, customer approval links, and proposal PDF generation.

The publicly hosted page demonstrates the product idea. Private project workflows are not exposed to the internet without the necessary authentication and security controls.
